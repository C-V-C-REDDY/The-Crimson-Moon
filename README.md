# The Crimson Moon

> A 7-floor dark fantasy dungeon crawler. Descend. Survive. Reclaim.

## Play
[Play on itch.io](https://t.co/DOxAxNmpdH)

## About
Play as Luna, the Moon Elemental, descending through 7 floors 
of ancient darkness to face what should never have woken.

## Features
- Wave-based combat across 7 floors
- 4 enemy types — Melee Warrior, Shadow Ninja, Orb Mage, Summoner
- Boss floor — survive the slash storm
- Mana-gated ability system — Dash, Stealth, Teleport
- Clovers of Medusa — collect to charge mana
- Persistent high score via FileAccess
- Full UI — battle cards, codex, pause menu

## Controls
| Action | Key |
|--------|-----|
| Move | WASD |
| Attack | Left Click |
| Dash | Z |
| Stealth | C |
